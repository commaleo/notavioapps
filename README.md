# Notavio — Landing Page

Website statis sederhana untuk Notavio, siap di-deploy ke Vercel.

## Struktur
- `index.html` — halaman utama
- `privacy.html` — Kebijakan Privasi
- `terms.html` — Syarat & Ketentuan
- `styles.css` — seluruh styling
- `vercel.json` — konfigurasi URL bersih

## Deploy ke Vercel
1. Upload folder/project ini ke GitHub, GitLab, atau Bitbucket.
2. Di Vercel pilih **Add New → Project** lalu import repository.
3. Framework preset: **Other**.
4. Build Command: kosongkan.
5. Output Directory: `.` atau kosongkan.
6. Deploy.

Alternatif: install Vercel CLI lalu jalankan `vercel` dari folder project.
